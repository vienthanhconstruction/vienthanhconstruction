Trang này đăng bài thẳng lên website. Cần một "mã truy cập" GitHub (chỉ làm một lần):

  1. Vào GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: chọn đúng kho vienthanhconstruction. Permissions → Contents: Read and write.
  3. Sao chép mã (bắt đầu bằng github_pat_) dán vào ô dưới.
